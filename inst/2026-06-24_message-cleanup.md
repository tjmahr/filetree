## Design Decisions

- Prefer user-facing layer wording, e.g. `data files`, over internal column names like `at_layer`.
- Describe conflicts as a comparison between the file name and parent directory when the file pattern disagrees with an already extracted layer value.
- Keep generated files out of manual edits.
- Use `{.var ...}` for extracted field names and `{.val ...}` for extracted values in problem messages.
- Do not use cli file or URL markup for file names because those can be treated as links.
- Use plain quoted filenames/directory names rather than file/url markup.
- Prefer "does not match a pattern at layer `...`" over "matches no pattern".
